## 🇮🇷 فارسی

### 🚀 معرفی

**SNI Scanner Pro** یک ابزار تحت وب **پیشرفته**، **سریع** و **کاملاً آفلاین** برای ارزیابی عملکرد سرورهای DNS و دامنه‌ها است. این ابزار با استفاده از **درخواست‌های HTTPS** و **تصویرنگاری مخفی** (Image‑based Ping)، معیارهای کلیدی شبکه را اندازه‌گیری می‌کند:

- **تاخیر (Latency)** – زمان رفت و برگشت پکت
- **جیتر (Jitter)** – نوسان تاخیر
- **پکت‌لاس (Packet Loss)** – درصد بسته‌های ازدست‌رفته
- **پایداری (Stability)** – کیفیت اتصال بر اساس ترکیب جیتر و پکت‌لاس

همه‌ی پردازش‌ها در مرورگر شما انجام می‌شود و **هیچ داده‌ای به سرور ارسال نمی‌شود**. این ابزار برای کاربران حرفه‌ای شبکه، مدیران سرور و توسعه‌دهندگانی طراحی شده که نیاز به **اسکن سریع و دقیق** دامنه‌ها برای تنظیم مسیریابی هوشمند دارند.

## 🇬🇧 English

### 🚀 Introduction

**SNI Scanner Pro** is an advanced, fast, and fully offline web‑based tool for benchmarking DNS servers and domains. It measures key network metrics using **HTTPS requests** and **image‑based hidden pings**:

- **Latency** – round‑trip time
- **Jitter** – latency variation
- **Packet Loss** – percentage of lost packets
- **Stability** – connection quality based on jitter & loss

All processing happens locally in your browser – **no data is ever sent to any server**. Designed for network professionals, server admins, and developers who need **fast and accurate** domain scanning for intelligent routing.

---

### ✨ Key Features

| Category | Features |
|----------|----------|
| **📥 Repository Management** | 4 default repos (Global, Iran, SAZ, DAX) with add/edit/delete/import/export |
| **⚡ Scanning Engine** | Concurrent scanning, pause/resume/cancel, dynamic timeout adaptation |
| **📊 Live Dashboard** | Interactive table with filter, search, sort, row selection, one‑click copy |
| **📈 Live Charts** | **Ping Trend** and **Jitter Distribution** with smooth animations |
| **🔔 Monitoring** | Periodic domain checks with status change alerts |
| **🎛️ Full Customization** | 6 themes, accent color, table density, font size, animation speed, column toggles |
| **💼 Profiles** | Save and load multiple setting profiles |
| **📜 History** | Auto‑saved scan history with replay capability |
| **🔊 Notifications** | Sound, vibration, desktop alerts, configurable toast duration |
| **🌍 Bilingual** | Full Persian and English support with instant switching |
| **⌨️ Keyboard Shortcuts** | Ctrl+Enter start, Ctrl+. stop, Ctrl+E CSV export, Ctrl+Shift+S settings, Ctrl+F search |
| **📤 Export Formats** | CSV, JSON, PDF, copy domains, auto‑save results |

---

### 🧠 Scanning Engine (How it Works)

- Each domain is tested with **configurable packet count** (default 4).
- Two paths (`/favicon.ico` and `/robots.txt`) are used to reduce filtering false positives.
- **Dynamic timeout** adjusts based on average latency of responding domains.
- **Jitter** is calculated as the standard deviation of latencies.
- **Stability** is determined by combining jitter and packet loss (Stable, Mostly Stable, Unstable).
- Concurrent scanning with thread control and safe pause/resume/cancel.

---

### 🖥️ How to Use (Step‑by‑Step)

1. Open `index.html` in your browser.
2. Under **Repositories**, click each to enable/disable. Use the **Manage** button to edit domains.
3. Adjust **Limit**, **Concurrency**, and **Timeout** sliders as desired.
4. Click **Start Scan**. The table and charts will populate live.
5. Use **Pause** and **Stop** buttons during scanning.
6. Use the toolbar buttons for **Filter Online**, **Filter Slow**, **Select All**, **Re‑Ping**, and **Export CSV/JSON/PDF**.
7. Click the **📋** icon next to any domain to copy it. Click **🔍** to view full details.
8. Use **Quick Scan**, **Check Connection**, **History**, and **Monitor** for quick access.
9. Click **Settings** (⚙️) to customise everything and save profiles.

### 🗄️ Repository Structure

- **Global** – Popular international domains (Google, GitHub, Cloudflare, Microsoft, etc.)
- **Iran** – Domestic Iranian domains (Digikala, Divar, Snapp, Tapsi, Aparat, etc.)
- **SAZ** – Chinese and cloud service domains (Baidu, Alibaba, Tencent, Huawei, OpenAI, etc.)
- **DAX** – Short‑link and URL‑shortening services (t.co, bit.ly, tinyurl, etc.)

Use the **Manage** button to create new repos, add/remove domains, sort, deduplicate, and import/export.

### 📦 Dependencies

This project has **zero external libraries** besides **Google Fonts (Vazirmatn & JetBrains Mono)** loaded via CDN. All logic is contained in a single HTML file.

### 🚀 Deploy to GitHub Pages

1. Create a new public repository.
2. Place `index.html` in the root.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` and the `/ (root)` folder.
5. Click **Save**. After a few minutes, the tool will be live at `https://its-thesaz.github.io/<repo-name>/`.
